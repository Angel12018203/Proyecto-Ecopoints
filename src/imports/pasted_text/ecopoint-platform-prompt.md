# ECOpOINT — Plataforma web de reciclaje y recompensas

Diseña y prototipa una **plataforma web responsive llamada "Ecopoint"**, enfocada en reciclaje, sostenibilidad, educación ambiental y recompensas mediante un sistema de **Ecopuntos**.

El objetivo es crear un prototipo web funcional y coherente en Figma, donde todas las pantallas estén conectadas mediante navegación y las funcionalidades principales puedan simularse.

La interfaz debe conservar una identidad visual **moderna, profesional, limpia, tecnológica y ecológica**, similar a un dashboard SaaS moderno.

---

# 1. IDENTIDAD VISUAL

## Nombre

**Ecopoint**

El logotipo debe incluir un símbolo relacionado con una hoja y reciclaje.

El nombre debe escribirse como:

Utilizar:

* "Eco" en verde.
* "point" en un tono oscuro.

El logotipo debe ser minimalista y profesional.
